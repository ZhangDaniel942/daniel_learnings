## 1, 异常抛出, 异常捕获, 自定义异常等

### 1.1, 异常抛出, 异常捕获

```python
#!/usr/bin/env python

# -*- coding: utf-8 -*-
# @Time    : 2026/2/15 15:03
# @Author  : ivanl001
# @File    : a05_exception.py
# @Project : daniel_learning_code

"""
Description: 1, 异常拦截处理 2, 异常抛出等
"""

# 1, 异常拦截处理
try:
    # result = 1/0
    # print(a)
    pass
except ZeroDivisionError:
    print('遇到异常: ZeroDivisionError')
# except Exception as e:
#     print("所有异常都能拦截: excepppp:" + str(e))
except:
    print('发生其他异常, 但是不需要打印具体异常...')
else:
    print("没有异常的时候会进入else中")
finally:
    print("最后finally代码块")

# 2, 异常抛出等
# 2, 方法定义者可以自行抛出异常
def is_valid_age(age):
    if age >= 150:
        # 自己抛出异常...
        raise Exception('年龄不合法')
    else:
        return True

# 方法使用者来具体的捕获处理异常
try:
    is_valid_age = is_valid_age(1000)
    print(f"年龄是否合法: {is_valid_age}")
except Exception as e:
    print("捕获到异常: " + str(e))
else:
    print("程序正常运行")
finally:
    print("finally代码块, 处理资源问题等")
```

### 1.2, 自定义异常

```python
#!/usr/bin/env python

# -*- coding: utf-8 -*-
# @Time    : 2026/2/15 15:29
# @Author  : ivanl001
# @File    : a11_cus_exception.py
# @Project : daniel_learning_code

"""
Description: 自定义异常
"""

class DanielException(Exception):
    def __init__(self, msg):
        self.msg = msg

age = 1000
if age > 150:
    raise DanielException("年龄太大啦....")
```

## 3, with关键字

```python
#!/usr/bin/env python

# -*- coding: utf-8 -*-
# @Time    : 2026/2/15 15:34
# @Author  : ivanl001
# @File    : a12_with.py
# @Project : daniel_learning_code

"""
Description: with关键字
"""

with open("./test.txt") as file:
    content = ""
    # 1, 固定chunk读取
    # while True:
    #     chunk = file.read(1024)  # 每次读取1024字节
    #     if not chunk:  # 如果没有更多内容了就退出
    #         break
    #     content += chunk  # 累加到content

    # 2, 一行一行读取
    for line in file:  # 直接迭代文件对象，会自动按行读取
        content += line

    # 如上两种方式都是一段一段读取, 读取不会有内存问题, 但是会往content里面拼接, 如果文件过大, content会有问题哈
    print(content)


print("代码结束")
```
