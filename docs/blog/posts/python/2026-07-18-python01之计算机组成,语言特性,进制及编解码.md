## 1, 计算机组成

### **运算器**(cpu)

计算机的“计算员”。负责算术运算（加减乘除）和逻辑运算（比较大小、判断真假）。在现代CPU中，运算器是核心部分。

### **控制器**(cpu)

计算机的“指挥官”。负责从内存中读取指令，并指挥其他部件协调工作。现代CPU中，控制器和运算器紧密集成。

### **存储器**(内存和外存)

计算机的“仓库”。分为内存储器（内存）和外存储器（硬盘等）。

- **内存**：临时存储，速度快，断电数据丢失（如RAM）。
- **外存**：永久存储，速度慢，断电数据不丢（如SSD、HDD）。

### **输入设备**

负责接收用户的指令和数据，并将其转换成电信号传给主机。如：**键盘、鼠标、麦克风、扫描仪、摄像头**。

### **输出设备**

负责将计算机处理后的电信号转换成人类能感知的形式。如：**显示器、音响、打印机**。



> #### 📌 说明
>
> - **CPU = 运算器 + 控制器 + 寄存器组 + 内部总线**
> - **存储器 = 内存储器（内存，如RAM）+ 外存储器（外存，如磁盘、SSD、光盘）**
> - 内存（主存）属于**内存储器**，磁盘属于**外存储器**
>
> **cpu能直接访问的叫内存, 不能直接访问的叫外存**

## 4, 编码和解码: ASCII, Unicode+UTF8等区别

```shell
# 1, ASCII: 最早的 字符集 + 编码和解码系统, 包含: 1,字符集: 比如a是97的映射关系, 2, 编解码方式: 97如何存储

# 2.1, Unicode: 全球统一的字符集, 需要制定对应的编码方式才能完成编解码的方式
# 2.2, UTF8, UTF16, UTF32是编码方式, 定义了映射的字符集, 是如何存储和解读的. 


ASCII         = 字符集 + 编码（二合一）

Unicode       = 纯字符集（只编号）
UTF           = 编码方案（怎么存）
Unicode + UTF = 完整的“字符→字节”转换链


“ASCII 本身就是从字符到字节的全部过程”
✔️ 对。ASCII 里 'A'=65，存储就直接存 65（0x41），没有第二步。

“Unicode 只是编号”
✔️ 对。Unicode 只管 '中'=20013，不管 20013 在内存里是 E4 B8 AD 还是 2D 4E。

“需要 Unicode + UTF 一起才能完成字符到字节的相互转换”
✔️ 完全正确。
'中' → [Unicode 表] → U+4E2D → [UTF-8 规则] → \xE4\xB8\xAD
```

```python
#!/usr/bin/env python

# -*- coding: utf-8 -*-
# @Time    : 2026/2/13 10:32
# @Author  : ivanl001
# @File    : a18_encode_decode.py
# @Project : daniel_learning_code

"""
Description: 编码和解码
"""

# 0, 字符
str1 = "你好中国"
print(type(str1))
print(str1)

# 第1步：字符 → Unicode 码点（纯编号）
for char in str1:
    # print(char)
    code_point = ord(char)          # 20013 (0x4E2D)
    print(char , code_point)

# 第2步：码点 → UTF-8 字节（编码）,  从字符 -> 字节: 编码, encode
byte1 = str1.encode(encoding="utf-8")
print(type(byte1))
# 一个汉子, 三个字节
print(byte1)

# 第3步：UTF-8 字节 → 码点（解码）, 编号的解码, 从字节 -> 字符: 解码, decode
decoded_code = byte1.decode(encoding="utf-8")
for char in decoded_code:
    code_point_again = ord(char)        # 20013
    print(code_point_again, char)
print(decoded_code)
```
