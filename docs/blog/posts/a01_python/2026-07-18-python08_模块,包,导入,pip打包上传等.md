## 2, \__all__: 模块导出限制, 

> 注意: \__all__只能限定from tools import *, 如果是 from tools import _name, 并拦不住
>
> \__all__ = []
>
> 对于模块和包来说, 都有同样的作用. 对于包而言, 需要把\__all__ = []写在\_\_init__.py文件中

```python
#!/usr/bin/env python

# -*- coding: utf-8 -*-
# @Time    : 2026/2/15 16:05
# @Author  : ivanl001
# @File    : tools.py
# @Project : daniel_learning_code

"""
Description:  工具类
"""
# 注意: __all__只能限定from tools import *, 如果是 from tools import _name, 并拦不住
__all__ = []

_name = "ivanl010"

def add(a, b):
    return a + b
```



## 3, \__name__: 代码执行限制

> 一般测试方法都要在main里测试
>
> 防止每次引用代码都会跑测试...

```python
#!/usr/bin/env python

# -*- coding: utf-8 -*-
# @Time    : 2026/2/15 17:16
# @Author  : ivanl001
# @File    : a07_name.py
# @Project : daniel_learning_code

"""
Description: __name__
"""

print(__name__)

# 如果是在自己代码里跑, __name__是main
# 如果是引入的时候, __name__是模块名: a07_name

if __name__ == '__main__':
    print(__name__)
    print("king")
```

## 6, 代码打包及安装打包文件

> **Python 代码打包成可分发的安装包，并通过 pip 进行安装使用**
>
> 

### 6.1, 安装setuptools库

```shell
pip install setuptools
```

### 6.2, 配置安装文件和编写readme.md文件

* 在需要打包的包外创建setup.py文件

```python
# 你用的 from distutils.core import setup 是旧式写法，distutils 已经被 Python 官方标记为废弃，推荐改用 setuptools：
# from distutils.core import setup
from setuptools import setup, find_packages


# # 注意: 虽然包名是daniel-tools,但是打包的结果是: daneil_tools-0.1.tar.gz.
# #      安装好之后, 真实的包名时: daniel-tools. 包名: 中横线. 包文件: 下划线.
# setup(
#   name="daniel-tools",      # 需要打包的名字
#   version="0.1",            # 版本
#   py_modules=["info"], # 需要打包的模块
# )

# 注意: 虽然包名是daniel-tools,但是打包的结果是: daneil_tools-0.1.tar.gz.
#      安装好之后, 真实的包名时: daniel-tools. 包名: 中横线. 包文件: 下划线.
setup(
    name="daniel-tools",
    version="0.1",
    packages=find_packages(),  # 自动发现所有包，比 py_modules 更灵活
)
```

* 同级目录编写readme.md

```md
### daniel的自己打包工具
```



### 6.3, 在setup.py的同级目录下进行构建

> 构建结束会在同级目录下生成build文件夹

```shell
python setup.py build
```



### 6.4, 进行构建压缩

```shell
python setup.py sdist
```



### 6.5, 在等级目录下找到: ./dist/*.tar.gz就是我们的包



### 6.6, 打包的包的安装使用

```shell
pip install path_to_your_package/dist/your_package_name-0.1.tar.gz
# 安装后即可使用
pip install /Users/code/daniel/daniel_learning_code/a02_ai/a01_sgg/a01_python基础/day11/package/dist/daneil_tools-0.1.tar.gz
```



### 6.7, 你学到的这个流程在实际开发中的位置

```
开发阶段 → 编写代码
    ↓
打包阶段 → 你学的这套（setup.py + build + sdist）
    ↓
分发阶段 → 可以上传到 PyPI（`twine upload`），让全世界的人 `pip install`
    ↓
使用阶段 → 用户 `pip install 你的包`
```

> 你现在学的是**打包阶段**，如果将来你想把包发布到公共 PyPI 供别人下载，还需要用到 `twine` 工具上传，那就是**分发阶段**的内容了。
