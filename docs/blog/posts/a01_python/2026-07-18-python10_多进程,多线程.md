### 1.2, 队列的使用

Queue的常用方法

* qsize()：返回队列的大致长度。由于多线程或者多进程的上下文，这个数字是不可靠的。

* empty()：如果队列是空的返回 True。由于多线程或多进程的环境，该状态是不可靠的。

* full()：如果队列是满的返回 True。由于多线程或多进程的环境，该状态是不可靠的。

* put(obj[, block[, timeout]])：将 obj 放入队列。如果可选参数 block 是 True（默认值）而且 timeout 是 None（默认值），将会阻塞当前进程，直到有空的缓冲槽。如果 timeout 是正数，将会在阻塞了最多 timeout 秒之后还是没有可用的缓冲槽时抛出 queue.Full 异常。反之（block 是 False 时），仅当有可用缓冲槽时才放入对象，否则抛出 queue.Full 异常（在这种情形下 timeout 参数会被忽略）。

* put_nowait(obj)：相当于 put(obj, False)。

* get([block[, timeout]])：从队列中取出并返回对象。如果可选参数 block 是 True （默认值）而且 timeout 是 None（默认值），将会阻塞当前进程，直到队列中出现可用的对象。如果 timeout 是正数，将会在阻塞了最多 timeout 秒之后还是没有可用的对象时抛出 queue.Empty 异常。反之（block 是 False 时），仅当有可用对象能够取出时返回，否则抛出 queue.Empty 异常（在这种情形下 timeout 参数会被忽略）。

* get_nowait()：相当于 get(False)。



| 特性         | `multiprocessing.Queue()`  | `Manager().Queue()`     |
| :----------- | :------------------------- | :---------------------- |
| **存储位置** | 在创建它的进程中           | 在独立的 Manager 进程中 |
| **传递方式** | 通过 pickle 序列化整个队列 | 传递代理对象（轻量级）  |
| **适用场景** | 直接创建的 Process         | 进程池、网络通信等      |
| **性能**     | 较快（直接内存访问）       | 较慢（需要 IPC）        |
| **可靠性**   | 在进程池中可能有问题       | 稳定可靠                |

#### **Process 方式：fork 复制**

```
时间线 →
├── 主进程创建 Queue
├── 主进程 fork 子进程
│   ├── 子进程1：继承了父进程的内存空间
│   └── 子进程2：继承了父进程的内存空间
└── Queue 在所有进程中都是"活的"
```

#### **Pool 方式：预先创建进程**

```
时间线 →
├── 创建 Pool → 立即 fork 4个子进程（此时还没有 Queue）
├── 主进程创建 Queue
├── 提交任务 → 需要把 Queue 发送给已经存在的子进程
└── Queue 必须被序列化（pickle）后发送
```



### 1.3, 多进程之间通讯Queue

```python
#!/usr/bin/env python

# -*- coding: utf-8 -*-
# @Time    : 2026/2/19 15:46
# @Author  : ivanl001
# @File    : a10_process_communication.py
# @Project : daniel_learning_code

"""
Description: 进程间通信
进程A（生产者）         操作系统          进程B（消费者）
    │                     │                    │
    │ queue.put(data)     │                    │
    │────────────────────>│                    │
    │                     │ 将数据复制到         │
    │                     │ 内核缓冲区/共享内存   │
    │                     │────────────────────│
    │                     │                    │ queue.get()
    │                     │                    │<────────────
    │                     │ 将数据复制到         │
    │                     │ 进程B的内存          │
    │                     │────────────────────>│
    │                     │                    │ 使用数据
"""
import multiprocessing
import os
import random
import time


# 两个进程, 一个进程向队列中写入数据, 一个进程从队列中读取
def put_queue(queue):
    while True:
        num = random.randint(1, 100)
        queue.put(num)
        print(f"进程: {os.getpid()}, 向队列中放入数据: {num}")
        time.sleep(0.3)

def get_queue(queue):
    while True:
        num = queue.get()
        print(f"进程: {os.getpid()}, 从队列中读取: {num}")

if __name__ == '__main__':

    
    # queue = multiprocessing.Queue()
    # p1 = multiprocessing.Process(target=put_queue, args=(queue,))
    # p2 = multiprocessing.Process(target=get_queue, args=(queue,))
    # p1.start()
    # p2.start()
    # p1.join()
    # p2.join()

    queue = multiprocessing.Manager().Queue()
    processPool = multiprocessing.Pool(2)
    p1 = processPool.apply_async(put_queue, args=(queue,))
    p2 = processPool.apply_async(get_queue, args=(queue,))
    processPool.close()
    processPool.join()

    print("done")
```
